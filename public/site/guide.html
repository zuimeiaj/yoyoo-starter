打开编辑器

快速上手

5 分钟完成你的第一个页面

1

打开编辑器

点击右上角「打开编辑器」。首次打开会自动载入示例页面（介绍页 / 数据看板 / 系统架构图 / 协作脑图），无需注册登录，数据保存在浏览器本地。

2

拖入组件

编辑器左侧的图标工具条列着全部基础组件。按住图标拖到画布即可放置；点击选中组件，拖动移动，四角 / 四边手柄缩放，外侧圆弧手柄旋转。

3

编辑属性

选中组件后，右侧属性面板可调整：位置尺寸、旋转、背景色、边框、圆角、阴影、文本内容、对齐方式等。文本 / 形状 / 表格等组件也可双击直接编辑内容。

4

绘制连线（流程图 / 脑图）

顶部工具栏打开「连线」工具，所有组件四边出现锚点。按住锚点拖向目标组件锚点，松开即建立连接；轻点已连接锚点可断开。点击画布上的线可选中，Delete 删除。连线在组件移动缩放时自动跟随。

5

管理页面

左侧面板切换 / 新建 / 复制 / 删除页面，每个页面独立尺寸与背景色。分组：选中多个组件后按分组快捷键，打包成容器整体移动。

6

导出成果

顶部「导出」按钮：导出当前页为 PNG / JPEG 图片，或导出整个项目为 ZIP 压缩包。导出的图片包含连线、图表与全部样式，所见即所得。

小贴士

⌨️

常用快捷键

Ctrl+Z 撤销 / Ctrl+Shift+Z 重做 · Ctrl+C/V 复制粘贴 · Delete 删除 · Ctrl+Shift+O 切换框选模式（相交 / 包围）。

🔄

数据不丢

所有编辑自动保存到浏览器本地。换浏览器 / 清缓存前可先导出项目 JSON 备份。

🤖

AI 生成页面

页面数据是纯 JSON（组件树 + 属性 + 连线）。按 AI_PAGE_GUIDE.md 数据结构文档，让 AI 直接生成页面 JSON 导入即可渲染。
