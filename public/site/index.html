为什么选择 yoyoo

一个轻量、开箱即用的页面设计工具，覆盖从原型到成品的全流程。

🖱️

拖拽式编辑

组件拖入画布即用，拖动 / 缩放 / 旋转、对齐参考线与吸附、框选批量操作，编辑体验接近专业设计工具。

🔗

连线与流程图

组件四边锚点拖出连线，贝塞尔曲线或直角避障路由自动绕开组件，流程图、架构图、脑图随手可画。

📊

数据组件

柱状 / 折线 / 面积 / 饼 / 雷达图表，表格、单选多选、下拉、输入框 —— 表单与数据展示一站配齐。

📄

多页面管理

一个项目多个页面，独立画布尺寸与背景，大纲面板管理页面与组件层级，分组（block）自由嵌套。

🖼️

一键导出

页面导出 PNG / JPEG，整个项目打包 ZIP 下载。所见即所得，导出结果与画布一致（含连线）。

🔒

数据本地化

页面数据保存在浏览器 IndexedDB，无需注册登录，开箱即用。撤销 / 重做、多级历史记录随时回退。

适合谁用

从原型设计师到前端开发者，都能在 yoyoo 里找到效率。

🧑‍🎨

产品 / 设计师

快速产出页面原型与流程图，和团队讨论交互与信息架构，导出图片直接放进文档。

🧑‍💻

前端开发者

用可视化方式搭建页面骨架，连线表达模块依赖，图表与表格数据直接配置。

🎓

教学 / 演示

画架构图、思维导图、数据看板原型，零成本上手，即时分享成果。
