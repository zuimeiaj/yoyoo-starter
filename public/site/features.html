功能特性

围绕「拖拽生成、零代码编辑」打造的一套完整能力

编辑器体验

以专业设计工具的交互标准构建的画布编辑体验

🖱️

拖拽 / 缩放 / 旋转

组件拖入画布，四边与四角手柄自由缩放，外侧圆弧手柄旋转。移动量化 1px 级跟手。

📐

对齐与辅助线

拖拽中自动吸附参考线，显示与相邻组件的对齐提示与间距标注，排版对齐零心算。

🔲

框选批操作

相交 / 包围两种框选模式，拖拽过程实时高亮命中组件，松手批量选中，一次移动 / 复制 / 删除。

⚡

快捷键与撤销

复制粘贴、删除、分组、对齐、层级调整等常用操作全快捷键支持；撤销 / 重做多级历史。

🧱

分组（block）

多组件打包成分组容器，整体移动缩放；分组前后渲染结果完全一致，可随时解组。

📑

多页面

一个项目多页面，各自独立尺寸与背景；页面列表随时切换、复制、删除，数据互不干扰。

组件能力

内置 30+ 常用组件，覆盖文本、表单、图形与数据展示

📝

文本与按钮

双击直接编辑内容，字号 / 颜色 / 加粗 / 斜体 / 下划线 / 行高字距可调，高度自动包裹。

⌨️

表单组件

单行 / 多行输入、下拉选择、单选多选，选项即配即用，默认选中项一键标记。

📊

数据图表

柱状 / 折线 / 面积 / 饼 / 雷达五种图表，多系列混合展示，数据表格直接填写。

🔷

图形与流程节点

矩形、圆、三角、直线、菱形（判断）、平行四边形（输入输出）、六边形（循环），双击加标签。

🖼️

图片与图标

图片支持铺满 / 等比 / 拉伸三种填充模式，内置 iconfont 图标库即拖即用。

📋

表格

二维数据直填，行高列宽占比、单元格合并、按单元格独立配色样式。

连线 —— 流程图 / 架构图 / 脑图

组件四边锚点拖出连线，连接即跟随组件移动缩放

🔗

两种线型

贝塞尔曲线与直角折线一键切换；直角线自动避障，绕开所有组件与自身，箭头永不穿组件。

🧲

锚点吸附

按住锚点拖出虚线，悬停目标锚点自动高亮吸附；轻点已连接锚点可断开该点全部连线。

🔄

零同步成本

连线只存引用不存坐标，组件拖动 / 缩放 / 画布缩放滚动，连线实时跟随，多对多自由连接。

产出与数据

设计成果与数据都掌握在你自己手里

🖼️

图片导出

当前页或整个项目导出 PNG / JPEG，或打包 ZIP 下载；连线、图表、圆角阴影完整保留。

💾

本地持久化

页面数据自动存入浏览器 IndexedDB，刷新不丢失；结构化的 JSON 数据可导出迁移。

📦

AI 可生成

页面由纯 JSON 描述（组件树 + 属性 + 连线），AI 按数据结构文档即可直接生成完整页面导入。
